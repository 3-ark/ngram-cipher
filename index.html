🔏 English N-Gram Cipher Tester

Accepts model IDs (e.g. onnx-community/Supra-Mini-v2-0.1M-ONNX) or Hugging Face URLs. Model downloads directly from Hugging Face on first run and caches in browser IndexedDB.
⚠️ Warning: LLM steganography method is experimental and not reliable yet. Too many variables can corrupt decoding if extra attention is not paid. For decoding to succeed, the following variables must match identically:
  • Library version: @huggingface/transformers & ONNX Runtime versions.
  • Model weights: Exact model repository, commit revision, and quantization format (e.g. fp16 vs q4).
  • Hardware & platform: CPU architecture/SIMD instructions, GPU/WebGPU driver precision, or WASM runtime environment.
  • Configuration: Generation prompt context, bits per token, and sampling settings.
